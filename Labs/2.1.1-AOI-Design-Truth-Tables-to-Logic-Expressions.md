# 2.1.1 AOI Design: Truth Tables to Logic Expressions

## Overview

Digital logic design begins with clear design specifications. A truth table lists every possible binary input combination and the corresponding output for a circuit. From a completed truth table, you can write an unsimplified Boolean logic expression.

In this activity, you will translate design specifications into truth tables and write unsimplified logic expressions in Sum-of-Products (SOP) form. You will also reverse the process by creating truth tables from logic expressions.

## Learning Objectives

By the end of this activity, you should be able to:

- Translate design specifications into truth tables.
- Write unsimplified logic expressions from truth tables.
- Create truth tables from logic expressions.
- Identify minterms associated with output values of `1`.
- Determine the relationship between the number of inputs and the number of possible input combinations.

# Part A: Truth Tables to Logic Expressions

## Truth Table Conventions

A truth table models how a logic-circuit output responds to all possible input combinations.

- Input variables appear in the left columns.
- Output variables appear to the right of the input columns.
- Inputs are listed in ascending binary-count order.
- A circuit with $N$ inputs has $2^N$ possible input combinations.

For example, a two-input circuit has:

$$
2^2 = 4
$$

possible input combinations.
