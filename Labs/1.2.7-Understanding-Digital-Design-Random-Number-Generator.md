# 1.2.7 Understanding Digital Design: The Random Number Generator

## Overview

The Random Number Generator (RNG) combines three major sections of an electronic system:

- An analog section that produces the timing behavior.
- A digital sequential logic section that produces a repeating count.
- A digital combinational logic section that converts the count into a die-face LED pattern.

In this project, you will use Circuit Design Software (CDS) to build and test each section, combine them into a complete Random Number Generator, and compare combinational and sequential logic.

## Learning Objectives

By the end of this project, you should be able to:

- Use CDS to build and test a multi-section circuit.
- Differentiate between combinational and sequential logic.
- Test a combinational logic circuit with a truth table.
- Test a sequential counter using clock cycles.
- Combine analog, sequential, and combinational circuit sections.
- Explain how the RNG simulates the values on a six-sided die.

### Procedure

1. Start the simulation.
2. Cycle the `CLOCK` input until the initial output value is `001`.
3. Remember: one clock cycle equals two switch toggles, LOW to HIGH and back to LOW.
